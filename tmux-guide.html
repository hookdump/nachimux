00 El prefix

Casi todos los atajos empiezan con el prefix: lo presionas, lo sueltas y recién entonces presionas la tecla siguiente. nachimux usa el estándar de tmux: Ctrl+b.

Cuando esta guía dice prefixw significa: presiona Ctrl+b, suelta ambas teclas y luego presiona w. No hay que mantener todo apretado a la vez.

01 Instalación rápida

El instalador activa este perfil sin pisar archivos ajenos. Después, el doctor te dice exactamente qué falta.

1. Dependencias

En macOS, instala tmux y las pequeñas herramientas de la interfaz.

brew install tmux gum fzf zoxide

2. Activar nachimux

./nachimux setup
nachimux doctor

¿Qué hace setup?

  • Enlaza el comando en ~/.local/bin.
  • Activa el perfil desde ~/.tmux.conf.
  • Recarga tmux si ya está abierto.
  • No reemplaza archivos que no reconoce.

Los plugins se instalan una sola vez con TPM. Dentro de tmux: Ctrl+b, suelta, y luego I.

el atajo para todos los atajos

★ La paleta de comandos

¿No recuerdas una tecla? No pasa nada. Presiona prefixp y aparece un buscador. Escribe lo que quieres — split, new tab, zoom, rename — y Enter lo ejecuta.

prefix p

Búscalo y ejecútalo

Aquí viven las acciones comunes, agrupadas por categoría. Cada fila muestra su atajo y Enter la ejecuta. Cerrar una tab o un split siempre pide confirmación.

La paleta y nachimux leen el mismo registro. Para consultar sin ejecutar, usa prefix/.

02 Tres niveles

tmux contiene tres tipos de objetos. nachimux los presenta como conceptos familiares para que siempre sepas en qué nivel estás trabajando.

● Workspace

Un contexto completo

tmux lo llama session. Idealmente uno por proyecto. Aparece a la izquierda.

  • prefixw
  • Buscar / crear / renombrar / eliminar
● Tab

Una pantalla del workspace

tmux lo llama window. Son las pestañas centradas en la barra superior.

  • prefixt
  • Nueva tab; Tab para avanzar
● Split

Un panel dentro de una tab

tmux lo llama pane. Permite tener dos shells lado a lado.

  • prefix= prefix-
  • Lado a lado / arriba y abajo
todo a la vista

★ El sidebar de workspaces

Presiona prefixb para mostrar una columna con todos los workspaces. El actual se expande y muestra sus tabs. Puedes hacer click en cualquier fila para saltar allí. Vuelve a presionar prefix b para ocultarlo.

05 Tus primeros cinco minutos

Crea un workspace

Presiona prefixw, escribe el nombre de un proyecto y Enter.

Abre un par de tabs

Usa prefixt dos veces. Cambia entre ellas con prefix y luego Tab.

Divide una tab

prefix= los pone lado a lado; prefix- los apila. Muévete con prefix h/j/k/l.

Copia algo sin el mouse

prefixEsc activa scroll, v selecciona y y copia al portapapeles.

Sal sin cerrar nada

prefixd te desconecta. Vuelve con tmux a; todo sigue ejecutándose.

06 El comando nachimux

Todos los atajos viven también en un CLI buscable. Ábrelo dentro de tmux con prefix/. La consulta y la paleta ejecutable comparten exactamente los mismos datos.

# buscar cualquier atajo
nachimux
# buscar directamente un tema
nachimux split
# comprobar que todo está listo
nachimux doctor
# volver a abrir esta guía
nachimux docs
dónde vive cada cosa
