the only key you have to remember

00 The prefix

Nearly every shortcut starts with the prefix: you press it, let go, and only then press the next key. nachimux uses the tmux standard: Ctrl+b.

When this guide says prefixw it means: press Ctrl+b, let go of both keys, then press w. You never hold them all down at once.

from nothing to working

01 Quick install

The installer activates this profile without stepping on anyone else's files. The doctor then tells you exactly what is missing.

1. Dependencies

On macOS, install tmux and the small tools the interface leans on.

brew install tmux gum fzf zoxide

2. Turn nachimux on

./nachimux setup
nachimux doctor

What does setup do?

  • Links the command into ~/.local/bin.
  • Activates the profile from ~/.tmux.conf.
  • Installs TPM and its plugins.
  • Reloads tmux if it is already running.
  • Never replaces a file it does not recognise.

Setup installs the plugins for you. If that step cannot finish it says so — then, inside tmux: Ctrl+b, let go, then I.

nachimux uninstall undoes all of it, and only touches what setup created.

Can't remember a key? It doesn't matter. Press prefixp and a search box appears. Type what you want — split, new tab, zoom, rename — and Enter runs it.

the mental model

02 Three levels

tmux has three kinds of object. nachimux presents them as things you already know, so you always know which level you are working at.

● Workspace

A whole context

tmux calls it a session. Ideally one per project. It shows on the left.

  • prefixw
  • Find / create / rename / close
● Tab

One screen of the workspace

tmux calls it a window. These are the tabs centred on the top bar.

  • prefixt
  • New tab; Tab moves along
● Split

A pane inside a tab

tmux calls it a pane. It lets you put two shells side by side.

  • prefix= prefix-
  • Side by side / top and bottom
one door, four rooms

★ Finding anything

Press prefixg and you get every tab in every workspace, searchable. There used to be four separate keys for this, and you had to pick the right one before you could see anything — which is exactly the knowledge you opened a finder to get.

Now the mode switches from inside, so a wrong guess costs a keystroke instead of a reopen: ctrl+a all tabs · ctrl+r recent · ctrl+n asking for you · ctrl+w workspaces.

The old keys still work

prefix f, prefix B and prefix n open the same finder on a different filter, and prefix W opens it on workspaces by recency. Muscle memory survives; you just get one surface instead of four.

A tab that wants you — a finished Claude turn, or a bell — turns yellow in the bar and shows up under ctrl-n, pointing at the exact split that called.

↺
Sessions are saved every 15 minutes, and never restored on their own (continuum, with auto-restore off). Opening tmux always gives you a clean start — but if a recent save exists the bar says so, and prefix C-r takes it. prefix D says not this time.

learn by doing

05 Your first five minutes

Make a workspace

Press prefixN, type a project name, and Enter.

Open a couple of tabs

Use prefixt twice. Move between them with prefix then Tab.

Split a tab

prefix= puts them side by side; prefix- stacks them. Move with prefix h/j/k/l.

Copy something without the mouse

prefixEsc starts scrolling, v selects, and y copies to the clipboard.

Leave without closing anything

prefixd detaches you. Come back with tmux a; everything is still running.

for when you forget

06 The nachimux command

Every shortcut also lives in a searchable CLI. Open it inside tmux with prefix/. Looking things up and running them share exactly the same data.

# search every shortcut
nachimux
# jump straight to a topic
nachimux split
# check everything is in place
nachimux doctor
# check the cheatsheet still matches the real bindings
nachimux doctor --keys
# open this guide again
nachimux docs
